# 目标院校要求核验

只有用户已经确定目标院校、具体专业和学位时才进行核验。该步骤用于检查当前项目与既定目标的要求是否匹配，不用于推荐学校。

## 来源优先级

1. 当前申请季的院校官方作品集或申请要求；
2. 用户提供的当前申请季官方文件；
3. 院校官方专业页面、申请指南和 FAQ；
4. 经过整理的内部知识；
5. 其他来源只作线索，不作为最终依据。

页数、格式、大小、视频、命名和提交方式等易变信息必须实时核验。记录学校、专业、学位、申请季、页面链接与核验日期。

找不到官方信息、来源冲突或无法联网时，明确标为“暂未核实”，继续完成有依据的通用项目预审。不要把历史要求、录取案例或社交媒体内容冒充当前官方规则。
